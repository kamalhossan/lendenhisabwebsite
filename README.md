# লেনদেন হিসাব — ওয়েবসাইট

অ্যাপের পরিচিতি ওয়েবসাইট আর গোপনীয়তা নীতি। শুধু HTML + CSS (কোনো বিল্ড বা প্যাকেজ নেই), তাই Vercel-এ সরাসরি চলে।
অ্যাডমিন প্যানেলের সঙ্গে কোনো সম্পর্ক নেই — প্যানেলের ঠিকানা এখানে কোথাও নেই।

## পাতা

| ঠিকানা | ফাইল | কী আছে |
|---|---|---|
| `/` | `index.html` | হোম: সুবিধা, তিন ধাপে শুরু, দাম (ফ্রি / পেইড — যোগাযোগ), সাধারণ প্রশ্ন, ডাউনলোড |
| `/privacy/` | `privacy/index.html` | গোপনীয়তা নীতি, বাংলা + ইংরেজি (স্টোরের Privacy Policy লিংক) |
| ভুল ঠিকানা | `404.html` | "পাতাটি পাওয়া যায়নি" |

বাকি ফাইল: `assets/style.css` (সব ডিজাইন), `assets/logo-*.png`, `favicon.*`, `apple-touch-icon.png`, `robots.txt`, `vercel.json` (পরিষ্কার URL ও নিরাপত্তা হেডার)।

ডিজাইন: অ্যাপের মতোই সবুজ `#057a55`, Noto Sans Bengali; মোবাইলে সব এক কলামে। হোম পাতার ফোনের ছবিটা ছবি নয়, HTML দিয়ে আঁকা অ্যাপের নমুনা।
Claude-এর "লেনদেন হিসাব — ওয়েবসাইট ডিজাইন" ক্যানভাসে একই ডিজাইন আছে।

## নিজের কম্পিউটারে দেখা

ফোল্ডারে যেকোনো স্ট্যাটিক সার্ভার চালান, যেমন `npx serve .` তারপর ব্রাউজারে `http://localhost:3000`।

## Vercel-এ ডিপ্লয়

1. ফোল্ডারটা GitHub-এ একটা রিপোজিটরিতে তুলুন (বা `npx vercel` চালান)।
2. Vercel → Add New → Project → রিপোজিটরি বাছুন। Framework Preset: **Other**; Build Command ও Output Directory খালি রাখুন।
3. Deploy। তারপর Project → Settings → Domains → আপনার ডোমেইন যোগ করে Vercel যে DNS রেকর্ড দেখায় সেটা ডোমেইন কেনার জায়গায় বসান।
4. স্টোরে Privacy Policy লিংক: `https://<আপনার ডোমেইন>/privacy/`

## যা বদলাতে হবে পরে

- **ডাউনলোড বোতাম:** `index.html`-এর শেষের দিকে। "APK ডাউনলোড করুন" বোতাম যায় `https://github.com/kamalhossan/lendenhisabwebsite/releases/latest/download/lenden-hisab.apk`-এ — GitHub Releases-এর সর্বশেষ রিলিজের `lenden-hisab.apk` ফাইল। APK ১০০ MB-এর বেশি বলে রিপোতে বা Vercel-এ রাখা যায় না; Releases-এ ২ GB পর্যন্ত চলে, আর লিংকের মেয়াদ শেষ হয় না।
  - **নতুন বিল্ড দিলে:** GitHub → রিপো → Releases → Draft a new release → নতুন ট্যাগ (যেমন v1.0.1) → APK ফাইলটা **`lenden-hisab.apk`** নামে তুলে Publish। ওয়েবসাইটের লিংক বদলাতে হয় না, নিজেই নতুনটায় যায়। শুধু JS-এর পরিবর্তন OTA-তে যায়, তখন নতুন APK লাগে না।
  - রিপো public হতে হবে, নাহলে ব্যবহারকারী ফাইল পাবেন না।
  - Google Play বোতাম এখনো "শিগগির"; প্রকাশ হলে `href="#"`-এর জায়গায় স্টোরের লিংক দিন আর `aria-disabled="true"` তুলে দিন।
